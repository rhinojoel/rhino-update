# Rhino website

A static starter for the new website, styled with Tailwind CSS.

## Files

- `index.html`: page content, styled with Tailwind classes
- `src/input.css`: Tailwind entry file
- `dist/styles.css`: built CSS (committed, so the page works without a build)

## Working on it

```
npm install
npm run dev     # rebuilds the CSS as you edit
npm run build   # one-off minified build
```

Then open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
